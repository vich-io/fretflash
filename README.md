# fretflash

A click-paced guitar fretboard-recall drill.

Run `python3 -m http.server 4173 --bind 127.0.0.1`, then open
http://127.0.0.1:4173/. No browser build step is needed.

Use Node.js 22+ and run `npm test` for unit checks. Where `check:runtime` and
`test:browser` are listed in package.json, run them too after installing the
locked development dependencies and Chromium.
